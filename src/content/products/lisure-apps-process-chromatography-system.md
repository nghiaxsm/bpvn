## Overview

The **APPS Process** is a low-pressure process chromatography system designed for large-scale production of biological products. The system is integrated, modular and standardized, with multiple configurations to accommodate different process requirements.

It supports automated chromatography operations, including equilibration, sample loading, washing, elution, fraction collection, cleaning and regeneration. Lisure states that system documentation is available to support qualification and validation for customers operating in cGMP-regulated environments.

## Key Features

- **Multiple system configurations:** A range of models covers different flow-rate ranges and process requirements.
- **Hygienic design:** Designed to comply with ASME BPE and cGMP requirements.
- **Automated chromatography workflows:** Supports equilibration, sample injection, washing, elution, collection, cleaning and regeneration.
- **Multiple control platforms:** Available control options include Emerson DeltaV, Siemens WinCC and CBS software developed based on LabWindows.
- **Regulatory support:** CBS software is stated by Lisure to comply with FDA 21 CFR Part 11 requirements.
- **Qualification and validation documentation:** Documentation support is available for cGMP-regulated customers.
- **Industrial components:** Core components are sourced from internationally recognized manufacturers.

## Configurations

The APPS Process series is available in multiple configurations to cover different process flow-rate ranges, piping requirements, installation footprints and utility conditions. The appropriate configuration should be selected according to the process requirements and confirmed with Lisure.

## Applications

The system is designed for process-scale chromatography in the large-scale production of biological products. The appropriate system configuration depends on the process flow-rate range, piping requirements, facility utilities and the chromatography process to be implemented.

## Configuration and Selection

Configuration selection should be based on the required operating flow rate and maximum flow rate, together with piping size, available power supply, installation footprint and process requirements.

For cGMP-regulated projects, confirm the required automation platform, software functions, documentation package and qualification/validation deliverables with the manufacturer.
