## Product Overview

The **Lisure Pilot-Scale Chrom System DN8** is a pilot-scale chromatography system designed for flexible process operation and online monitoring. The system is available in mobile chassis, rack and skid configurations to accommodate different installation and process requirements.

It uses a high-precision constant-flow pump designed for low pulsation and reliable long-term operation. The system supports multi-channel UV scanning across 200–400 nm, allowing simultaneous online monitoring at multiple wavelengths.

## Key Features

### Flexible installation

- Available in mobile chassis, rack and skid designs.
- Configurations are intended to provide flexibility for different installation layouts and process requirements.

### Reliable flow delivery

- Uses a high-precision constant-flow pump.
- Low-pulsation operation is designed to support reliable performance.
- Designed for long-term uninterrupted operation.

### Flexible valve configuration

- Pneumatic and electric valve groups are available.
- Valve-group selection can be matched to different applications and pressure requirements.

### Online multi-wavelength monitoring

- Supports multi-channel scanning across a wavelength range of 200–400 nm.
- Multiple wavelengths can be monitored online at the same time.

### Automatic control

- Fully automatic software control.
- Graphical user interface designed for straightforward operation.
- The manufacturer describes the software as providing a range of operating functions.

### Optimized UV detection

- A customized flow cell is available.
- The optical path can be adjusted according to sample concentration to optimize the UV detection signal.
